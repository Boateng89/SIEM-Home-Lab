# SIEM Home Lab

## Project Overview

This project documents my hands-on SIEM lab built to develop SOC analyst skills. The lab simulates a real security monitoring environment.

## Lab Architecture

| Component | Technology |
| :--- | :--- |
| SIEM Platform | Splunk Enterprise (free license) |
| Operating System (SIEM) | Ubuntu Server 22.04 LTS |
| Endpoint | Windows 10 |
| Log Forwarder | Splunk Universal Forwarder |
| Endpoint Logging | Sysmon |

## What I Built

- ✅ Ubuntu Server VM running Splunk Enterprise
- ✅ Windows 10 VM configured as endpoint
- ✅ Sysmon installed for detailed process logging
- ✅ Splunk Universal Forwarder sending logs to indexer
- ✅ Custom alerts created for failed login attempts (Event ID 4625)
- ✅ Security dashboard with three visualization panels

| Skill | How I Demonstrated It |
